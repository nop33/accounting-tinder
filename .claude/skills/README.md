# Vendored skills

These skills are copied from [mattpocock/skills](https://github.com/mattpocock/skills)
(plugin version 1.3.2, commit `4ae2317ddb22b046e26455e4f9c9b3aaaf62212d`), MIT licensed
(see `LICENSE-mattpocock-skills`).

They live in the repo, rather than being enabled as a plugin, so they load in every
Claude Code session on this project, including cloud sessions from Claude Desktop and
the mobile app, and stay scoped to this project only.

To update: re-copy the `skills/engineering/*` and `skills/productivity/*` folders listed
in the upstream `.claude-plugin/plugin.json` and bump the commit above.
